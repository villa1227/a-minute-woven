# 一刻织锦 · A Minute, Woven

使用 USB 摄像头的双眼候选直径与 BLE 手环心率，把一分钟的数据织成一幅个人作品。也可以不接设备，体验基础织纹生成。

## 快速开始

目前主要在 Windows、USB 摄像头和 Xiaomi Smart Band 10 上验证。需要 Python 3 和可用的蓝牙适配器。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

打开 http://127.0.0.1:8765 。设备接入、眼区框选与原始数据记录位于可展开的“设备与数据”区域。

## 数据织锦

无需设备即可试绘：双击 `web/render-artwork.html`，导入 [模拟作品参数](examples/artwork.synthetic.json)，便可预览和导出 PNG。自定义绘图与设备接入请参阅 [接口文档](docs/interfaces.md)，样例说明见 [examples](examples/README.md)。

- 点击“开始创作”，先准备并采集 5 秒，再从左向右逐渐画出第一段，同时采集下一段。原始采集共 60 秒，最后一段在 60～65 秒画完，最终共 12 段。
- 页面每 500 ms 查询后端进度，绘制使用屏幕刷新节奏（目标约 60 fps）和缓存图形。每段只使用已经固定的中位数，绘制过程中不变形；无设备时基础织纹也连续生长。
- 第 60 秒停止原始采集，第 65 秒允许下载。最后 5 秒仍属于创作期间，不能启动普通记录或更换眼区。
- 米白底上始终绘制基础织纹；有效的画面左眼、右眼数据分别叠加靛蓝、朱红细线，心率调节彩线密度。缺失值保持缺失，不会生成虚构生理读数。
- 每段使用有效样本中位数，各通道首次有有效数据的时间段作为本次个人参考。
- 已完成段保持固定；刷新页面可恢复当前服务进程中的进度。结束后下载 2400 × 3200 PNG，右下角预留二维码位置，当前不生成二维码。
- 每次创作的原始数据和完整作品参数 `artwork.json` 保存在本机 `recordings/`。取消会保留原始记录，但不提供完整作品下载。
- 服务仅监听本机回环地址；不会上传摄像头画面、心率或作品。生理数据映射用于艺术反馈，不表示心理状态或医学结论。

## 本地数据

`recordings/`、`diagnostics/`、`.deps/`、虚拟环境与缓存被 Git 忽略。仓库不包含个人采集记录、摄像头原图或蓝牙扫描快照。

在当前文件夹运行 `python app.py` 或双击 `start.bat`，打开 http://127.0.0.1:8765 。

## 实时反馈

- 顶部只显示画面左眼、画面右眼候选直径与实际心率，并显示最近 60 秒的简洁曲线。
- “记下当前值”使用各通道最近 10 秒内有效样本的中位数，后续显示当前值相对于该个人参考值的差（px / bpm）。参考值属于本次页面。
- 新参考至少需要 3 个有效眼区样本、2 个有效心率样本，并且通道仍有新数据。尚无数据的通道不设置参考。
- 切换摄像头、修改眼区或重新连接手环时，相应通道的参考值失效；建议姿势和光照稳定后重新设置。
- 缺失、失去接触和长时间无更新留空。心率旁的脉动按最新 BPM 控制动画速度，是频率示意，不是逐搏检测。
- 曲线悬停查看数值，记录期间的阶段标记显示为竖线。候选数据比例只表示有候选的帧占比。
- `/api/trace?after=<cursor>` 提供最近 180 秒的增量采样缓冲；使用与采集状态相同的会话令牌。绘图轮询不会补造传感器样本，也不要求先开始磁盘记录。
- Grove GSR 皮电已接入设备面板、实时曲线和同步记录；作品的颜色和密度暂沿用眼部与心率映射。参考 [可视化设计与报告说明](docs/visualization-notes.md) 编写报告。

## 表情分类

表情输入现已支持：在设备面板开启本机七类表情识别，默认目标 5 Hz，仅显示和同步记录，不影响作品。首次运行 `python scripts/download_expression_models.py` 安装模型，详见 [表情模块与接口](docs/expression.md)。

## Grove GSR 皮电

- 使用已验证的 `skin_sigma/skin_sigma.ino`：UNO、A0、115200 波特率，目标 20 Hz。报文格式为 `GSR,1,序号,millis,ADC`。
- 在主页面展开“设备与数据”，找到“Grove GSR 皮电”，刷新串口并选择 USB-SERIAL CH340（当前设备为 COM6），点击“连接皮电”。程序不会自动烧录或打开串口。
- 连接前关闭 Arduino IDE 串口监视器或 `skin_sigma/live_plot.py` 窗口，避免多个程序争用串口。打开串口可能使 UNO 重启，等待首条有效报文即可。
- 显示原始 ADC、实测接收频率、电脑/板端间隔及缺帧、重复、解析错误统计。超过 1 秒没有有效数据会停止显示当前值；曲线在缺帧、重启、回绕或长间隔处断开。
- 点击“记下当前值”时，皮电参考取最近 5 秒至少 20 个有效样本的中位数；重启或重新连接清除该通道参考。参考是本次页面的显示设置，不修改原始记录；刷新页面后需要重新设置。
- 单独连接皮电也可“开始记录”。`eda.csv` 和统一 `samples.jsonl` 保存在相同的 `recordings/日期_编号/`，创作期间也会记录皮电。CSV 的 `seq` 为主机记录序号，`device_seq` 为板端序号。
- 断开皮电不终止其他设备的同步记录。更换皮电连接前须先结束当前记录或创作。
- 保留 ADC 读数，不声称已标定电导率，不推断情绪；主机接收时间与板端 `millis()` 分别保存。

## 双眼采集

- 连续取图、识别和网页预览分开运行；识别默认目标 20 Hz，预览目标 20 fps，实际值取决于设备和处理速度。每次识别只处理最新帧，丢弃等待中的旧帧。
- 双眼均手动框选后跳过自动定位；自动定位按约 0.5 秒间隔运行。识别椭圆仅叠加最近 150 ms 内、同一眼区设置的结果；超过时限隐藏，不表示这帧重新识别成功。
- 面板显示取图/识别频率、取图/识别/编码耗时和识别帧龄。设备面板折叠或页面进入后台后暂停预览请求，后台采集不停止。
- 当前改进前的本地备份标签：`backup/gsr-before-smooth-render`（`a503865`），包含皮电接入；没有推送远端。

- 选择 `1 · HD webcam`，点击“打开”。自动模式分别寻找画面左侧和右侧的眼区。
- 自动检测不稳定时，选择“框选眼区”的画面左侧/右侧，分别在预览中拖动框住对应的单只眼睛。每侧可单独恢复自动；“双眼自动”清除两侧手动框。
- `IMG-L` 和 `IMG-R` 是未额外翻转的图像位置，不直接代表人的生理左眼/右眼。确定镜像关系后可在后续分析时建立对应关系。
- 两侧分别输出直径候选、位置和质量。单侧失败时该侧为缺失，不会复制另一眼或补零。
- 现阶段保留像素单位。之后用固定外壳约束相机与眼睛距离，再加入标定物建立尺寸换算；当前没有距离补偿。
- 算法是暗区轮廓候选检测，需要核对绿色椭圆是否贴合瞳孔。眼区框本身不是瞳孔边缘。

## 手环及同步记录

开启手环心率广播后，扫描并选择自己的 Xiaomi Smart Band 10，再点击连接。收到数据后可开始记录、添加阶段标记、停止保存。

2026-10-21 已实测此手环提供标准心率通知；当次 15 秒收到 12 条报文，未附带 RR 间期。程序保留原始报文及可选 RR 字段，不由 BPM 反推 HRV。

每次记录保存在 `recordings/日期_唯一编号/`：

- `metadata.json`：设备、采样设置、双眼手动区域和时钟说明。
- `samples.jsonl`：带统一主机时间戳的完整数据，双眼位于 `data.eyes.image_left` / `image_right`。
- `metadata.json`：格式版本为 2，包含未翻转画面坐标系和瞳孔候选算法版本。
- `camera.csv`：两眼各自独立的 `image_left_*` / `image_right_*` 列及完整眼部 JSON。
- `heart_rate.csv`：心率、接触状态、可选 RR 和原始报文。
- `eda.csv`：皮电 ADC、板端序号与时间、电脑接收间隔、断点标记及原始报文；异常报文和重启事件保存在 `samples.jsonl`。
- `frames/`：仅勾选保存采样原图后生成 JPEG。两眼共享该帧，便于重跑算法。

主机单调时钟用于对齐，UTC 用于追溯。它们是主机读取/接收时间，尚未校准相机、蓝牙的传输延迟。

停止记录后再更换摄像头。关闭网页不会自动停止服务；结束前停止记录、关闭设备，再在命令窗口按 Ctrl+C。

## 扩展接口

完整接口契约、数据字段、HTTP API 和扩展示例见 **[开发接口说明](docs/interfaces.md)**。

- 绘图交付：分享完成后的 `artwork.json`，使用 [离线重绘页面](web/render-artwork.html) 加载并导出，或调用 `Weave.draw()` 自定义 Canvas 页面。支持 v1/v2 作品；本地服务也提供 `/render-artwork.html`。
- 传感器交付：新增适配器使用 `acquisition.interfaces.SamplePublisher.publish(source, data, clock)` 发布真实采样，统一进入实时缓冲与原始记录；皮电已采用此接口。新增 source 的图表、CSV、作品映射需按接口文档显式接入。

`acquisition/eye.py` 提供双眼算法；`camera.py` 提供摄像头采集；`heart.py` 提供蓝牙传输与标准报文解析；`core.py` 提供线程安全记录。

`acquisition/eda.py` 复用 `skin_sigma/gsr.py` 的串口解析和采集，通过真实采样回调调用 `Recorder.emit('eda', data, clock)` 进入同一会话。独立绘图程序仍可单独使用，但不能与主程序同时占用同一串口。

安装依赖：`python -m pip install -r requirements.txt`。本机已安装的蓝牙与设备枚举依赖位于 `.deps/`，入口会自动加载。

验证：`python -m unittest discover -s tests -v`；可视化逻辑检查（需要 Node.js）：`node --test tests/test_feedback.cjs tests/test_weave.cjs`。`diagnose.py camera` / `diagnose.py ble` 用于硬件检查。
