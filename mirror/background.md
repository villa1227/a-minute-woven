# 背景涂绘版 · background-v1

底色整体浓度现默认 40%，可用“底色浓度”滑块调为 5%～100%。它作用于整个手绘背景图层，已画和新画内容一起变化，等于在现有笔刷 alpha 之外再乘该浓度；不修改墨迹像素或原始数据，不影响 woven 与黑色线稿。预览与作品/背景 PNG 一致。输入 JSON 的 backgroundOpacity 保存最终显示浓度，重绘时先还原背景透明画布，再用此 globalAlpha 合成；旧文件缺该字段时按 1。关闭/刷新后恢复默认，不跨照片自动保存参数。

## 可选 woven 织纹底层

“加入 woven 织纹背景”默认关闭。生成线稿后第一次勾选时开始当前页面的独立织纹过程；若生成前已勾选，则生成完成时开始。白纸上先放 woven，再放大笔刷背景、透明黑线和输入层。复用原 `web/weave.js` 的 drawBand，通过 `/woven-renderer.js` 只读提供；不修改旧 woven 页面、不启动原记录或原作品会话。

5 秒准备、每 5 秒固定一段，下一段时间左到右揭示；60 秒收满 12 段，65 秒画完。真实 trace 时间换算到当前页面单调时钟后聚合，每眼/心率取有效样本中位数，首次有效段各自作为参考，原幅度/线密度规则不变。皮电与表情仍用于画笔，不额外调制 woven。只使用开启后收到的真实 rows；重启跳过历史、不以轮询数充样本，已固定段不回写。缺失值留空，各段仍有原基础织纹。

关闭开关仅隐藏 woven，不清笔画、暂停计时或重启织纹；再次开启恢复当前位置。隐藏或后台期间仍按单调时间计算进度，回来补到当前位置，不重播。此功能是页面内创作：关闭/刷新页即结束，不具备原后端织锦会话的跨页面后台采集保证。换照片或重新生成线稿清空 woven，会按开关状态重新开始；“清除背景”只清手绘背景，保留 woven。

作品 PNG 和背景 PNG 均遵循 woven 当前开关；线稿 PNG 不包含 woven。woven 导出不带旧作品标题、日期和二维码留白，保留织纹本体和米白底。输入 JSON 新增 `woven:{included,artwork}`，包含当时 elapsed、固定 bands、参考与种子；layerOrder 加 woven。关闭时仍保留参数并标 included=false。纯笔画重绘继续使用 BackgroundBrushRenderer，完整背景重绘需要再按保存的 elapsed 对 woven bands 做对应宽度裁剪，叠于笔画下。开关只影响显示和导出，不改变原始笔画快照。

新增验证：`node --test tests/test_mirror_woven.cjs` 与 `node tests/check_woven_background.cjs`，覆盖分段聚合/去重、无设备基础织纹、计时、开关、导出合成和原笔画不变。无需开启真实设备。

2026-11-21 更新：默认标准线稿为 sigma=1.5、percentile=0.85、minHigh=20、minComponent=15、lowRatio=0.4；新版线宽默认 3 px。背景笔刷目标透明度为原来的 40%（再按 0.025 量化），关闭映射时透明度 0.30。renderer 升级 background-stamps-v2，旧 v1 快照仍可重绘；旧笔画不会重新变淡。“将当前定为预设”保存当前五项和线宽到当前浏览器 localStorage，两个镜子页下次打开共同使用，不保存图片、笔输入或设备地址。已有保存预设优先于内置默认，切换档位可恢复内置参数。

## 入口与版本保留

沿用 `python mirror/serve.py`，打开 http://127.0.0.1:8767/background 。原描摹版仍在 http://127.0.0.1:8767/ ，原织锦页面和文件保留。导航用新标签打开另一个版本，不替换当前页面的照片和笔画；刷新仍清空当前页面内存。原织锦入口 8765 需要原 `app.py` 运行；同时使用原织锦和镜子时，应先启动 app.py，再启动镜子，以复用同一 Controller。仅使用两种镜子时，一条镜子命令即可。

两个镜子页面共用同一个已鉴权设备接口及采集 Controller，各自保持独立照片、画布、参考值与设置。设备启停、ROI 和记录对共同采集器生效：一个页面停止设备，另一个页面也会缺失该通道。不要为版本各开一套采集器。新页面不增加摄像头采集，不自动开启设备；沿用拍照前释放采集摄像头的流程。

原描摹 app、tracing、sensors 和渲染器保持不变；新版拥有独立 HTML、照片处理适配、背景输入和渲染模块，复用图像算法、笔输入、数据映射与设备模块。后续修改其中一版时应只改对应版本文件，避免用新版覆盖旧版。

## 图层与使用

顺序为白纸 → 彩色背景 → 透明黑线稿 → 透明输入覆盖层。生成线稿后用笔或鼠标左键涂整张纸，包括人脸内部；没有人像分割、限制区域或自动生成路径。线稿不会被笔刷覆盖、染色或随数据重算；输入覆盖层不绘制墨迹。隐藏线稿只影响预览，不改变底稿内容、布局或作品导出。

基础直径默认长边的 6%，可调 2%～16%（步长 0.5%），显示实际图像像素。有效眼部参考存在且数据映射开启时：实际直径 = 基础直径 × clamp(当前平滑映射线宽 / 9.5, 0.5, 2)，再舍入到整数像素。9.5 px 是默认反馈强度 3、眼部变化为零的参考线宽，因此不额外抵消强度滑块的作用。没有有效眼部或关闭映射时，使用完整基础直径。长边 1600 的最大直径为 512 px，不是 512 个 CSS 像素。

表情、皮电和心率继续控制颜色/纹理、透明度/柔边、节奏。新笔刷将 softness 按 `clamp(原 softness/7.5,0,1) × 实际直径 × 0.12` 扩大，并结合 hardness 形成径向渐变边缘；纤维/颗粒纹理也按直径放大。心率摆动幅度保持原值，不随笔刷倍增。为复现与缓存，实际宽度舍入到 1 px、softness 到 0.5 px、hardness 到 0.05、opacity 到 0.025、纹理强度到 0.5，实际数值存入每段快照。

关闭数据画笔为固定基础直径的石墨色圆笔、透明度 0.85，不使用传感器；数据全缺失时也有稳定基础笔刷，不随机伪造反馈。原始压力不控制大小、不改写读数。按原规则处理悬停、侧键、触摸、越界、失焦及 50,000 点上限。

“清除背景”只清背景与本次输入，保留线稿和参考。“重新拍照”丢弃旧照片与背景；线稿参数重新生成会清背景与记录（界面说明提示），同照片仍保留参考。尺寸/强度改变只影响新落笔，不重画已有背景；窗口缩放只调整显示。照片及数据不跨页面复制、不自动保存。

## 缓存渲染与接口

`BackgroundBrush.adapt(mappedBrush, {longestSide, diameterPercent, eyeActive, mappingEnabled})` 返回完整的实际背景笔刷快照，不改变映射数据或原始笔输入。Node 可 require `background-renderer.js`，浏览器用全局 BackgroundBrush。v2 输出透明度为映射 opacity×0.4，量化到 0.025、限制到 0.025～0.4；关闭映射固定为 0.30。下文尺寸与缓存行为保持原样。

`new BackgroundBrush.BackgroundBrushRenderer(ctx, seed, makeCanvas?)`：`draw(sample, snapshot)` 绘制，`breakPath()` 断线。尺寸相关步距为 clamp(直径×0.1,2,12) px，按路径累计距离铺印记，插值仅为渲染，不添加 samples。每个样式缓存带透明度、柔边与纹理的离屏贴图，LRU 上限 24 张；相同样式只建一次。随机纹理来自固定 seed 和家族，不依赖刷新率或批次。调色和样式快照决定缓存键，避免逐点重算大量径向渐变。阴影效果是绘画反馈，不是物理水彩。

`MirrorBackgroundComposition.compose(includeLines)` 返回白底合成 Canvas；includeLines=true 总是画入原始透明线稿，即使预览隐藏了线稿。只有本页面保存的确认照片会生成线稿，不读取另一页画面。

## 下载与重绘

- 下载作品 PNG：白纸＋背景＋黑线，不含照片、输入层或界面。
- 下载背景 PNG：白纸＋背景，不含线稿。
- 下载线稿 PNG：白纸＋黑线，不含背景；保持原 PNG 的易用格式。
- 三种 PNG 均保持处理图像原尺寸及比例，没有 CSS 显示缩放；最大长边 1600，不放大小图。
- 输入 JSON 保留 schemaVersion=2 与原 samples、segments 等，新增 frontendVersion=background-v1、renderer=background-stamps-v1、layerOrder、baseDiameter、diameterPercent。baseDiameter 为导出时的当前设置，历史更改位于 configurationHistory 及每段的 brush 中。
- 各 brush 快照包含实际尺寸、基础直径、眼部倍率、配色与纹理、mappingVersion、renderer 等；renderSeed 为照片会话 ID。`BackgroundBrush.BackgroundBrushRenderer.replay(ctx,data)` 仅重绘背景到同尺寸透明空画布，不读取实时数据。JSON 不包含照片或线稿像素，重建完整作品需另存线稿 PNG。原描摹版的 `BrushRenderer.replay` 和 JSON 含义保持原样，不混用两个渲染器。

## 验证与局限

```powershell
node --test tests/test_background_brush.cjs
node tests/check_background_browser.cjs
```

浏览器脚本需要 Playwright、Edge 及镜子服务，使用合成笔/传感器样本，不操作真实设备；可选公开测试人像来源见 `tests/mirror-fixtures.md`，仅保存在忽略的 diagnostics/ 中。覆盖拍照镜像/释放、导入、透明线稿、图层交叠、尺寸、显隐、清除/换图、旧页面兼容、独立参考、导出与逐像素背景重绘。画布检查在交叠区域确认不透明黑线最终仍为黑色，透明区域能显色，输入层像素全透明。

最大 1600×1600 画布和 512 px 笔刷的离屏测试检查贴图缓存与重绘一致性；提交 Canvas 调用的时间不等于包含 GPU 合成、显示与设备输入的端到端延迟。实际 XP-Pen 手感与多设备场景仍需参与者试画，未完成实机部分不报为已验证。

2026-11-14 本机最大尺寸诊断：240 个路径样本使用同一 512 px 颗粒笔刷，贴图构建 1 次，提交绘图约 1 ms；包含全图 getImageData 强制读回约 106 ms。此为批处理离屏诊断，不是每帧耗时或笔尖到屏幕延迟。浏览器用合成设备状态确认两页同步变化、参考独立；实际服务三个入口 `/`、`/background`、`/background/` 返回同一 collector stream_id，检查未开启真实硬件。

黑色线稿始终在顶层，但石墨色或深色背景叠涂很密时，视觉对比仍可能降低；可减小反馈强度、换有效表情配色、减轻重复涂绘，或隐藏线稿比较底色。本版不擅自改写生理信号来获得指定颜色。
