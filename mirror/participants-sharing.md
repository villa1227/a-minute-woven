# 多人体验与 ImgLoc 作品分享

正式维护入口为 `/background`。旧描摹页及原织锦页保留作实验版本，本轮多人交接与分享仅加入正式背景版。

## 下一位参与者 / Refresh

页面顶部按钮重新加载本页，清掉照片、线稿、背景、woven、笔输入、参考值、作品链接、二维码及未完成的浏览器任务。下次从新的 trace cursor 开始，不把上一人的缓冲当新采样。保存到 localStorage 的线稿预设保留，设备连接仍运行。保留已落盘的历史 recordings，不删除他人的文件。

点击后先查询采集器状态：普通记录存在则停止并保存后才重载；停止失败保留画面并显示错误。原织锦创作仍运行时提示先结束，不替人取消作品。服务不可达时无法确认记录已停止，提示恢复连接再试；浏览器自身刷新仍可清掉页面，但不会保证后台记录结束。此操作影响共用采集器的普通记录，组织者应避免两个页面同时服务不同参与者。

清理只针对本页；另一个已经打开的实验标签不会被强制清空。正式现场建议仅开正式背景页。离开时触发既有 pagehide 清理，设备由本机采集器管理，无需每位参与者重新扫描。

## 完成并生成二维码

1. 画好后点击完成，定格当前白纸＋按开关显示的 woven＋按浓度显示的背景＋黑线稿。即使预览隐藏线稿，最终图也含黑线。
2. 定格后禁用照片替换、线稿参数、笔输入和设备操作；woven 同时停止展示计时。保留本地下载、重试上传和下一位按钮。图床失败不清作品，重试使用同一份 PNG。
3. 经受会话令牌与本机 Origin/Host 保护的 `POST /api/share/upload` 上传 image/png。长度最多 8 MB；Pillow 校验 PNG：宽 1～1600、高 1～1800 像素（含落款），并展平白底、重新编码以移除元数据。没有任意外部地址参数，不接受重定向。图片只在进程内存处理，不写本地上传目录。
4. 使用 ImgLoc 页面公开的 `POST https://imgloc.com/upload.php`，multipart 字段 `image`；返回 JSON `ok:true,url`，仅接受已核对的 HTTPS 图片域名 `i.imgs.ovh`。**默认保存约 1 年，不是临时自动删除**；无账号删除 API，不能保证用户随时删除。条款与常见问题：https://imgloc.com/terms.html 、https://imgloc.com/faq.html 。明确同意复选框勾选后才可分享；不同意可仅下载本地。每 IP 每小时最多 60 张，一分钟一人已接近上限，建议减少测试与重复上传；错误时保留本地文件。

5. 本地使用 qrcode-generator 1.4.4 生成二维码，不调用外部二维码服务。扫码指向图片 HTTPS 链接，手机通常需要长按保存或使用浏览器下载，不承诺自动进相册。活动网络和参与者手机都需能访问图床。

上传超时 45 秒、网页等待 55 秒。服务器仅保存最多 32 个图片内容哈希到链接的内存缓存，一小时内重复同图复用链接；该一小时是本地缓存有效期，不是图床自动删除时间；上传进行中拒绝并发，避免多人重复点击增加图床负担。HTTP 上传没有自动重试，失败由用户点击重试；断网后不能保证远端绝对没有接收一张图。下一位重载后不会显示旧异步请求结果，二维码被清空；它不会删除已经上传到远端的作品。图片按图床政策保留，不提供匿名远端主动删除入口。

图床请求遵循启动服务时 HTTP_PROXY/HTTPS_PROXY 环境；若现场需要 VPN 代理，可在终端设置后再启动镜子服务。不要在仓库配置真实账号或密钥。

## 测试与当前外部服务限制

`python -m unittest discover -s tests -p 'test_*.py'` 验证图片格式、大小、缓存、失败重试、鉴权。Playwright＋Edge＋镜子服务下运行 `node tests/check_share_browser.cjs` 和 `node tests/check_participant_browser.cjs`，使用合成接口验证冻结 PNG、二维码矩阵、失败重试、停止记录、清理隔离和预设保留。

2026-11-21 已完成新版服务的真实公网链路验证：纯几何测试作品由 `/api/share/upload` 上传 ImgLoc 成功，二维码经 OpenCV 解码得到对应图片链接，读回 PNG 为 600×872（画面 600×800，加 72 px 底部落款）。没有上传参与者照片或数据。Litterbox 原先出现 412，已从正式分享流程移除，不再提示切换 VPN 作为唯一解决办法。现场仍建议手机实际扫码，确认参与者网络可达。

## 成品展示与落款

分享区位于作品卡片内；桌面完成后只展示成品和右侧二维码，移动端成品后紧跟二维码，设备、拍照与高级参数收起。作画过程中设备设置、输入诊断及高级调参默认折叠。下一位入口始终可见。二维码不印进作品，不遮人像。

作品底部增加独立白色落款区：高度 max(64,round(画面宽×0.12)) px；上海时区时间戳（UTC+08:00）在上，“Cyber Mirror”居中在最下方。时间来自本页该图生成时的 createdAt；JPEG 原始元数据不导出。PNG 和 ImgLoc 上传使用同一个合成函数，分享冻结后展示完全相同的 Canvas，重试使用相同 Blob。背景/纯线稿下载保持原画面尺寸，不附作品落款。

`tests/check_final_presentation_browser.cjs` 默认 mock 上传；显式设置 `MIRROR_REAL_UPLOAD=1` 才上传一张纯几何测试作品并验证界面。测试截图与 QR 仅放在忽略的 diagnostics/share/，不纳入仓库。第三方二维码库本地加载，许可见 mirror/vendor/NOTICE.md。
